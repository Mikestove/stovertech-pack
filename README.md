# StoverTech

A Minecraft modpack for **Minecraft Java 1.21.1** with **NeoForge 21.1.258**, made for
playing together on a small private server. It mixes building, cozy farming, exploring and
tech, with extra help for younger players who are new to survival.

## Install

You need [Prism Launcher](https://prismlauncher.org/) and a Minecraft Java account.

1. Download **[StoverTech-Prism.zip](https://github.com/Mikestove/stovertech-pack/releases/latest/download/StoverTech-Prism.zip)**.
   (Not the green "Code" button. That zip is only the file list below, and Prism can't use it.)
2. In Prism: **Add Instance**, then **Import**, then **Browse**, pick the file, and click **OK**.
   You can also paste the download link into the Import box.
3. Press **Play**. The first start downloads every mod, which takes a few minutes. After that,
   the pack updates itself each time you press Play, fetching only what changed.

The instance asks for up to 6 GB of memory; change it in the instance's settings if needed.

## What's inside

**Building and machines:** Create

**Tech:** Mekanism (with Generators and Tools), Applied Energistics 2

**Magic:** Ars Nouveau

**Farming, cooking, cozy:** Farmer's Delight, Handcrafted, Macaw's Furniture, Supplementaries,
Comforts, Rechiseled

**Exploring:** Biomes O' Plenty, When Dungeons Arise, YUNG's Better Dungeons and Better
Mineshafts, Artifacts, Friends & Foes, Naturalist

**Getting around:** Waystones, Sophisticated Backpacks, Xaero's Minimap and World Map

**Playing together:** Open Parties and Claims (protect your builds), Simple Voice Chat
(proximity voice), PvP Flag (players only fight when both opt in)

**Help and quality of life:** JEI (recipes), Jade (what am I looking at), AppleSkin,
Mouse Tweaks, FallingTree (cut one log, the whole tree falls; sneak to cut one log)

**Looks and speed:** Sodium, Iris with the Complementary Reimagined and BSL shader packs
(Complementary is switched on at first start; press O to change), ModernFix, FerriteCore

**Server tools:** spark, Simple Backups

Plus the libraries these need.

### Made for this pack

- **Robot Buddy:** every player gets a robot friend that follows them, fights monsters,
  guards an area or hunts for food. Pick from several designs and any dye color, and upgrade
  it with chips. It never dies; it powers down and can be repaired. The in-game **Robot Buddy
  Book** explains everything.
- **Family Basics:** the StoverTech main menu, the Family Cookie, and server rules suited to
  young players: you keep your items when you die, and there's no fall damage.
